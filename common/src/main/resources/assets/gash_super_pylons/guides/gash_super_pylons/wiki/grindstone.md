# Grindstone Upgrade

Use the [Wrench in Bind mode](workshops.md) to link an [XP Tank](xp_tank.md) and an item pylon within five blocks. Put the enchanted item in the main pylon. Grindstone removes ordinary enchantments, keeps curses and deposits XP in the tank.

With [Super](super.md), it captures enchantments, including curses, in books and produces zero XP. Each book holds one enchantment plus one per Quantity tier. Enable the server setting `grindstoneConsumesBooks` to consume one plain book from the item auxiliary for each output book. It defaults to `false`.

Output goes to the working-side inventory. Hit the main pylon to withdraw it manually, starting with the disenchanted item.
