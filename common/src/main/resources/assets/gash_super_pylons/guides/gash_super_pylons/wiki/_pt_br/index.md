# Gash's Super Pylons

Faça um Super Pylon com oito barras de ferro ao redor de tijolos de pedra talhados. No Criativo, procure a aba do mod com o ícone do pylon.

<GameScene zoom="3">
  <Block id="gash_super_pylons:super_pylon" y="1" />
  <Block id="minecraft:chest" />
</GameScene>

Clique com o botão direito para depositar. Um pylon básico guarda até 2.048 itens exatamente iguais, incluindo os dados do item. Bata para retirar um item ou agache e bata para retirar uma pilha. No Criativo, use uma picareta para quebrar o pylon.

Clique com um upgrade na mão para instalar. Agache e clique com a mão principal vazia para retirar o upgrade estampado mais à direita. Se houver um gerador e um processador, o gerador sai primeiro.
