# Ferramentas

## Wrench

Agache e use a rolagem do mouse para alternar os modos.

- **Vincular:** Siga o passo a passo de [Oficinas avançadas](workshops.md) para selecionar o pylon principal e vincular os auxiliares.
- **Direção:** agache e clique com o botão direito no ar para percorrer os seis lados. Clique com o botão direito no pylon para aplicar o lado de trabalho. O padrão é embaixo.

## Copy Paste Tool

Agache e clique com o botão direito num pylon para copiar os tipos e tiers instalados. Clique no destino para aplicar a configuração usando os upgrades do seu inventário. Os substituídos são devolvidos. Se faltar algum, o chat lista o que falta e a configuração não é aplicada.

## Paint Tool

Com um bloco na mão secundária, clique com o botão direito para usar sua textura na estrutura. Sem um bloco na outra mão, agache e clique para copiar a textura da estrutura ou clique normalmente para aplicar a textura salva. Se a textura estiver indisponível, a estrutura usa ferro.

Paint e Copy Paste mostram brilho e tooltip quando guardam dados. Agache e clique com o botão direito no ar para limpar os dados dessas ferramentas ou a seleção da Wrench no modo Vincular.
