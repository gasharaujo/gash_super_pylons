# Tools

## Wrench

Sneak and scroll to switch modes.

- **Bind:** Follow the steps in [Advanced Workshops](workshops.md) to select the main pylon and link its auxiliaries.
- **Direction:** sneak and right-click in the air to cycle the six directions. Right-click the pylon to set its working side. The default is down.

## Copy Paste Tool

Sneak and right-click a pylon to copy the installed upgrade types and tiers. Right-click a target to apply the setup using upgrades from your inventory. Replaced upgrades are returned. If any upgrades are missing, the chat lists them and the setup is not applied.

## Paint Tool

With a block in the offhand, right-click a pylon to use that block's texture on the frame. Without an offhand block, sneak and right-click to copy a frame texture or right-click to apply the saved one. If the texture is unavailable, the frame uses iron.

Paint and Copy Paste show a glint and tooltip while carrying data. Sneak and right-click in the air to clear their data or the Wrench's saved selection in Bind mode.
