# Advanced Workshops

The [Enchanter](enchanter.md) enchants items and books. The [Anvil](anvil.md) repairs gear and combines enchantments. Each workshop uses a main pylon and two linked auxiliary pylons.

## Link the pylons

1. Install Enchanter or Anvil on the **main pylon**. Leave its core empty while you set up the workshop.
2. Place **two auxiliaries** in the same dimension, 1 to 5 blocks from the main pylon. They may be above, below or to the side. Install **XP Tank** on one and leave the other able to store items. Use pylons that are free to join this workshop.
3. Hold the [Wrench](tools.md) in your main hand. **Sneak and scroll** until its tooltip shows **Bind**.
4. **Sneak and right-click the main pylon** with the Wrench. The chat confirms the selection.
5. Release Sneak. **Right-click each auxiliary** with the Wrench. The first two may be linked in either order. The chat confirms each link.

## Supply XP and collect the result

Feed the XP Tank by standing on it with XP, bringing XP orbs within two blocks or right-clicking it with bottles of enchanting. Each bottle adds 7 XP points and returns a glass bottle. Keep the space under the XP Tank clear of players while filling it.

Add the material listed on the upgrade's page to the item auxiliary, then put one input in the main pylon. The workshop runs automatically on its Speed cycle. Put a chest on the main pylon's working side, **below** by default. Keep that position free of linked auxiliaries. If the chest is full or absent, hit the main pylon to collect the result from its core.

If the workshop waits, check the main pylon's tooltip for missing links, materials or XP.
