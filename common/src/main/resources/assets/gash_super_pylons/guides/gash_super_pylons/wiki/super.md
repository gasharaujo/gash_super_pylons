# Super Upgrade

Adds orbiting Nether Stars and changes how compatible upgrades work. Anvil copies an enchanted book into a plain book and keeps the donor. Grindstone captures enchantments in books, with one extra enchantment per Quantity tier. Enchanter can bind a blacklist auxiliary. On a HUB, Super allows linking across any distance and dimension while the chunks are loaded.
