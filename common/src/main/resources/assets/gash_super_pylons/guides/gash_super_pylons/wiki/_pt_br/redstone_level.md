# Upgrade de Nível de Redstone

Emite sinal de 0 a 15 conforme o preenchimento. A leitura prioriza energia quando há um upgrade de Energia, depois fluidos, XP ou itens. Com Redstone instalado, o lado de trabalho é a saída de sinal.
