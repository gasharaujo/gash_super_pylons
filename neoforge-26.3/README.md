# Minecraft 26.3

Use Linux ou Windows com Java 25. O projeto usa NeoForge 26.3.0.113.

O JAR padrão inclui as integrações AE2, Jade, JEI, WTHIT e The One Probe. Quando tiver os JARs do Ponder e do Catnip para 26.3, inclua as cenas Ponder no build:

```powershell
.\gradlew.bat build '-PponderJar=C:\caminho\ponder.jar' '-PcatnipJar=C:\caminho\catnip.jar'
```
